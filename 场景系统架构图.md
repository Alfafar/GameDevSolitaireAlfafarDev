## 预制体选择逻辑 (Prefab Selection Logic)

```
假设 map.csv 配置：
prefab: "Panel1|Panel2|Panel3"

游戏运行时：

Day 1 (day=1):
    index = Clamp(1-1, 0, 3-1) = 0
    → 使用 Panel1

Day 2 (day=2):
    index = Clamp(2-1, 0, 3-1) = 1
    → 使用 Panel2

Day 3 (day=3):
    index = Clamp(3-1, 0, 3-1) = 2
    → 使用 Panel3

Day 4+ (day>=4):
    index = Clamp(4-1, 0, 3-1) = 2
    → 使用 Panel3 (最后一个)

总结：
- 数组从0开始索引
- day从1开始计数
- 超过数组长度时使用最后一个元素
```

## 时间控制逻辑 (Time Control Logic)

```
假设 map.csv 配置：
opentime: "9|10|11|12|13|14|15|16|17"

游戏运行时检查：

当前游戏时间 = 8点 (hour=8):
    if 8 in [9,10,11,12,13,14,15,16,17]:
        ✗ 不在开放时间内
        → 地图显示为"关闭"或不可访问

当前游戏时间 = 10点 (hour=10):
    if 10 in [9,10,11,12,13,14,15,16,17]:
        ✓ 在开放时间内
        → 玩家可以进入地图

当前游戏时间 = 20点 (hour=20):
    if 20 in [9,10,11,12,13,14,15,16,17]:
        ✗ 不在开放时间内
        → 地图显示为"关闭"
```

## 完整示例：森林场景 (Complete Example: Forest Scene)

```
1. Unity场景文件
   📁 Assets/Scenes/Map/Forest.unity
   包含：
   - 地形、树木、天空盒
   - 主相机位于 Environment/MainCamera
   - 空对象 ForestEntrance 作为玩家生成点

2. UI预制体
   📁 Assets/Resources/ForestPanel.prefab
   包含：
   - Canvas
   - 对话框
   - 任务列表
   - 按钮

3. map.csv配置
   1800015,魔法森林,3,6|7|8|...|18,Forest,ForestPanel|ForestPanel,UI/图标,Environment/MainCamera,ForestEntrance,Idle,1

4. 加载流程
   玩家点击地图 → MapPanel检测点击
   → SceneLoadManager.Load(1800015)
   → MapFactory.GetCA(1800015) 返回 MapCA
   → UnloadScene(当前场景)
   → LoadScene("Forest", Additive)
   → LoadPrefab() 
   → UIManager.OpenPanel("ForestPanel")
   → 场景加载完成！

5. 运行时状态
   - Unity场景: Forest.unity 已加载
   - UI面板: ForestPanel 实例已创建
   - 玩家角色: 位于 ForestEntrance 位置
   - 可操作性: ctrl=1，玩家可以移动
   - 开放时间: 6:00-18:00
```

## 设计模式说明 (Design Pattern)

本系统采用了以下设计模式：

1. **工厂模式 (Factory Pattern)**
   - MapFactory 负责创建 MapCA 对象
   - 统一管理对象创建逻辑

2. **数据驱动设计 (Data-Driven Design)**
   - 配置存储在 CSV 文件中
   - 无需修改代码即可添加新场景
   - 策划可以直接编辑配置

3. **单例模式 (Singleton Pattern)**
   - 管理器通过 CBus 访问
   - 确保全局唯一实例

4. **分层架构 (Layered Architecture)**
   - 配置层 (CSV)
   - 数据层 (MapCA, MapFactory)
   - 管理层 (SceneLoadManager)
   - 资源层 (Unity Scenes, Prefabs)

这种设计使得添加新场景变得简单快捷！🚀
