## 🎯 快速开始 / Quick Start

### 开发者指南 / Developer Guide

1. **查看未完成任务** / **Check Incomplete Tasks**
   - 阅读 [未完成任务清单.md](./未完成任务清单.md) 或 [INCOMPLETE_TASKS.md](./INCOMPLETE_TASKS.md)
   - 了解哪些功能需要实现 / Understand which features need implementation

2. **选择任务** / **Choose a Task**
   - 优先实现高优先级任务 / Prioritize high-priority tasks
   - 从核心系统开始 / Start with core systems

3. **开发提交** / **Development and Submission**
   - 遵循活动要求进行开发 / Follow activity requirements for development
   - 在场景ID表中标注你的场景 / Mark your scenes in the Scene ID table
   - 按时提交你的工作 / Submit your work on time

## 🎮 开发要求 / Development Requirements

### 必须遵守 / Must Follow:
1. ✅ 为每个场景添加场景编号 / Add scene numbers to each scene
2. ✅ 在《场景ID表》中标注开发者信息 / Mark developer info in Scene ID table
3. ✅ 按时提交所有变更 / Submit all changes on time
4. ✅ 不制作违法和敏感内容 / No illegal or sensitive content
5. ✅ 线性或珍珠链叙事结构 / Linear or pearl-chain narrative structure
6. ✅ 收束选项，保留唯一后置选择 / Converge options, keep single follow-up
